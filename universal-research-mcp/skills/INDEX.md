# Built-in research skills

Every skill below ships with the package and is registered automatically. Each is individually callable (via its tools) and composable by the deep-research orchestrator.

- `web-search` — Universal web search across providers with normalization. (tools: `search_web`, `search_multi`)
- `search-operators` — Understand and apply site:/filetype:/intitle:/inurl:/phrase/OR/-. (tools: `search_operator`, `build_search_query`)
- `query-builder` — Build search queries including operator-aware. (tools: `build_search_query`, `validate_search_query`)
- `query-expansion` — Expand a topic into query variants. (tools: `expand_query`)
- `query-refinement` — Refine a query with domain/filetype/exact. (tools: `refine_query`)
- `web-crawler` — Bounded relevance-guided crawl from seeds. (tools: `crawl_web`)
- `web-reader` — Fetch and extract readable page content. (tools: `fetch_source`)
- `link-discovery` — Extract outbound links from a page. (tools: `extract_links`)
- `document-research` — Research documents incl. office types. (tools: `search_documents`, `fetch_source`)
- `pdf-research` — Research PDF documents (parse/search/extract). (tools: `pdf_research`, `search_documents`)
- `spreadsheet-research` — Extract from XLSX/CSV documents. (tools: `spreadsheet_research`)
- `presentation-research` — Extract from PPTX documents. (tools: `presentation_research`)
- `github-research` — Research GitHub repos/code/issues/releases. (tools: `search_github`, `github_repository`, `github_code_search`, `github_issues`, `github_releases`)
- `code-search` — Search source code across providers. (tools: `search_github`, `github_code_search`)
- `academic-research` — Search papers on arXiv/Crossref. (tools: `search_academic`, `paper_research`, `literature_review`)
- `government-research` — Site-targeted official/gov research. (tools: `search_government`)
- `news-research` — News search with freshness. (tools: `search_news`)
- `community-research` — Community sources (HN, issues, forums). (tools: `search_community`)
- `source-analysis` — Classify source authority/type/freshness. (tools: `get_skill`, `source_analysis`)
- `evidence-extraction` — Map claim->evidence->source->location. (tools: `extract_evidence`)
- `claim-verification` — Verify a claim across independent sources. (tools: `verify_claim`)
- `contradiction-search` — Seek criticisms/limits/failures. (tools: `find_contradictions`)
- `fact-checking` — Verdict vocabulary with evidence. (tools: `fact_check`)
- `comparison` — Compare entities/sources across dimensions. (tools: `compare_entities`, `compare_sources`)
- `error-investigation` — Investigate an error message deeply. (tools: `investigate_error`)
- `literature-review` — Structured academic literature sweep. (tools: `literature_review`)
- `competitive-research` — Compare competing solutions/entities. (tools: `compare_entities`)
- `knowledge-graph` — Persist research graph of Q/C/E/S relations. (tools: `research_graph`, `research_status`)
- `deep-research` — Autonomous end-to-end research composing all skills. (tools: `deep_research`, `research_plan`, `research_status`, `cancel_research`)
