# n8n OpenCode skill

Copy this entire directory to `.opencode/skills/n8n/` or `~/.config/opencode/skills/n8n/`. OpenCode V2 also discovers `.opencode/skills/n8n/SKILL.md`.

The requested canonical file is `skill.md`; `SKILL.md` is included for current loader compatibility. Install and configure the sibling `n8n-full-mcp` server, then load the `n8n` skill for n8n tasks.
