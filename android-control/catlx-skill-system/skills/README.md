# Skill set — Universal Software Engineering

Agent Skills (`SKILL.md`) that teach **how to decide**. Tools live in MCPs.

| Skill | When |
|-------|------|
| `software-engineering` | Any build/maintain request (load first) |
| `mcp-routing` | Choosing Office / SQL / Windows / Android / SE |
| `requirements-analysis` | Vague product requests |
| `technology-selection` | Choosing language/template |
| `architecture` | Module boundaries |
| `implementation` | Writing code |
| `testing` | Verification |
| `debugging` | Failures |
| `security` | Before ship / secrets |
| `performance` | Slowness |
| `release-engineering` | Artifacts |
| `web-applications` | Sites and HTTP |
| `cli-applications` | CLIs |
| `desktop-applications` | Desktop GUIs |
| `libraries-and-apis` | Packages and backends |
| `structure-and-sdlc` | ASCII trees, boilerplate layouts, 21-phase SDLC catalog |

Install: clone this `skills/` folder into the agent's skills path, or set the workspace root so the agent can read these files.
