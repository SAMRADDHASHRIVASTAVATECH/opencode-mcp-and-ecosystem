# Knowledge layer

This directory preserves the operational text of *The Ultimate Blender Animation Knowledge Graph* v2.0, distributed so skills are not empty wrappers and so depth is not summarized away.

- `system/` — preface, journey, registers, relationship map, Ultimate Test, decision trees, appendix, glossary, hotkeys
- `domains/` — base chapters 1–15 (D01–D129 + extras referenced there)
- `depth/` — master-depth chapters 16–40

Skills **operationalize** this material (activation, procedures, I/O, delegation). When executing a skill, load the files listed in that skill's frontmatter `knowledge:` list, and go deeper here when the node card is not enough.

Completeness over brevity is binding. Do not replace these files with summaries.
