# Workflow: Character Pipeline (Chain 1)

```
concept (D03) → design (D04) → refs (D07) → sheets (D08)
→ blockout (D16) → model/sculpt (D19/D22) → anatomy check (D21)
→ retopo (D23) → topology test (D24) → UV (D25) → textures/materials (D26–D32)
→ clothes/groom (D37–D47) → skeleton (D49) → IK/FK (D51/D52)
→ weights (D56) → deformation test (D58) → correctives (D59)
→ facial rig (D60) → rig sign-off → animation (D64)
```

Skills in order: `character-design` → `blender-foundations` → `modeling` ⇄ `sculpting-anatomy` → `lookdev` → `costume-groom` → `rigging` → `animation`.

Failure rule: if deformation fails, return to topology (modeling), not to weight painting.
