# Desktop and user reactivity
Research reviewed Desktop Mate, NekoAI, Clawd Pet, MiniCPM Desk Pet, AI Desktop Pet/Convai, Clicky Windows, Open-LLM-VTuber and OpenPets. Useful patterns adopted: one shared embodiment; cursor gaze rather than disruptive cursor capture; active-window anchoring metadata; agent activity narration; explicit listening/thinking/working/waiting states; local-first model routing; changed-screen gating; accessibility before vision; push-to-talk/transcript entry; and click/drag embodiment events kept separate from computer authority.

PADP improves on pet-only designs by routing every approved event through the same world model, attention, appraisal, affect, intention, audit and memory. The desktop watcher is disabled by default. When consented, it polls OS active-window/cursor metadata, optionally samples a heavily downscaled local frame for change ratio, and optionally summarizes UI Automation controls on Windows. Raw frames are neither sent to the LLM nor stored. Only foreground, meaningful changes may invoke semantic interpretation, rate-limited to one per ten seconds. Screen text is labeled untrusted and cannot authorize actions.

`interact` routes typed or transcribed utterances through the configured existing model when available, with deterministic fallback classification. It distinguishes conversation, information, task, feedback and interruption. Tasks create proposed goals; feedback enters learning; stop/pause interrupts immediately; important information enters provenance-marked memory. Voice adapters should submit final transcripts through the same method.

Configuration: `desktop_sensor_enabled` grants metadata observation; `screen_change_enabled` additionally permits local pixel sampling; `accessibility_enabled` permits local accessibility inspection. Each remains independent. Enable only after reviewing privacy. The avatar reads desktop cursor belief and adjusts gaze; it does not acquire input authority.
