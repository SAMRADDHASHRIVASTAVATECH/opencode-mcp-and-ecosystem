# Master requirements addendum: true desktop, user and screen reactivity
The implementation incorporates the requested requirement directly into PADP's operating policy (`skills/SKILL.md`) and runtime. User speech transcripts, typed input, name calls, interruptions, tasks, corrections, praise and important information enter `interact`, semantic intent routing and the same persistent event bus. Approved desktop events use OS metadata, accessibility, local changed-region estimation, structured state and only then optional rate-limited model interpretation. These paths converge on the existing world model, attention, appraisal, affect, intention, task, policy, capability, verification, experience and memory services. The avatar is a subscriber to this state, never a separate pet brain.
