# Skills Index

The repository ships the following individually-callable skills. Each is backed by a real engine function (see its SKILL.md) and is registered with the Universal PDF Orchestrator.


## PDF Creation

- **`pdf-create`** — Create PDFs from documents & data  

## PDF Management

- **`pdf-read`** — Universal text reading  
- **`pdf-inspect`** — Inspect a PDF into a structured profile  
- **`pdf-extract`** — Extract text/structure with provenance  
- **`pdf-ocr`** — OCR scanned / image-only pages  
- **`pdf-render`** — Render PDF pages to images  
- **`pdf-vision`** — Visual interpretation of pages/figures  
- **`pdf-tables`** — Detect & extract tables as structure  
- **`pdf-search`** — Search within a PDF  
- **`pdf-index`** — Build a reusable search index  
- **`pdf-chunk`** — Context-safe chunking for large/small-model docs  
- **`pdf-summarize`** — Summarize with bounded context  
- **`pdf-qa`** — Question answering over a document  
- **`pdf-analyze`** — Analyze a document  
- **`pdf-edit`** — Structural page editing  
- **`pdf-annotate`** — Add annotations  
- **`pdf-merge`** — Merge PDFs  
- **`pdf-split`** — Split a PDF  
- **`pdf-reorder`** — Reorder / reverse / duplicate pages  
- **`pdf-rotate`** — Rotate pages  
- **`pdf-crop`** — Crop pages  
- **`pdf-scale`** — Scale / resize pages  
- **`pdf-watermark`** — Add watermarks & stamps  
- **`pdf-header-footer`** — Add headers, footers, page numbers  
- **`pdf-metadata`** — Read / write / remove metadata  
- **`pdf-bookmarks`** — Bookmarks / outline / TOC  
- **`pdf-links`** — Hyperlinks  
- **`pdf-forms`** — Forms: detect, list, extract, flatten  
- **`pdf-fill-forms`** — Fill AcroForm fields  
- **`pdf-sign`** — Signatures  
- **`pdf-encrypt`** — Encrypt / password-protect  
- **`pdf-decrypt`** — Decrypt / remove protection  
- **`pdf-permissions`** — Permission handling  
- **`pdf-redact`** — True content redaction  
- **`pdf-compress`** — Reduce file size  
- **`pdf-optimize`** — Optimize with quality profiles  
- **`pdf-repair`** — Diagnose & repair damaged PDFs  
- **`pdf-convert`** — Convert to/from other formats  
- **`pdf-export`** — Export PDF content/data  
- **`pdf-compare`** — Compare two PDFs  
- **`pdf-diff`** — Page/text diff report  
- **`pdf-images`** — Embedded image operations  
- **`pdf-document-state`** — Persistent per-document knowledge state  
- **`pdf-provenance`** — Track source provenance  
- **`pdf-batch`** — Batch operations over many PDFs  
- **`pdf-validation`** — Validate PDF & operation outputs  
- **`pdf-orchestrate`** — Universal PDF Orchestrator (SYSTEM MODE)
