# Templates

Reusable skeletons for document generation. See `content-model.md` for the
full content-flowable schema used by `pdf-create`.

| File | Use |
|---|---|
| `content-model.md` | authoritative spec of the content flowable types + page options |
| `report-template.json` | example content tree for a report (cover + headings + tables) |
| `invoice-template.json` | invoice skeleton (title block + line-item table + totals) |
| `content/sample.md` | a small Markdown input you can pipe through `create_from_markdown` |
