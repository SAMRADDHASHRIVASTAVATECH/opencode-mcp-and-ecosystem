# Lookdev Handoff Checklist

- [ ] UVs: seams hidden, islands packed, texel density consistent
- [ ] Maps: albedo (no lighting baked in), roughness, normal, masks
- [ ] Hero materials built in Principled (or NPR system if stylized)
- [ ] Skin SSS / eyes / teeth approved on a close-up
- [ ] Materials hold up under FINAL lighting, not just HDRI studio
- [ ] Style rules (D138) respected
- [ ] Lookdev lock requested
