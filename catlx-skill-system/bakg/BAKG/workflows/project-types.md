# Workflow: Project Types → Customized Journeys

| Project type | Skippable stages | Emphasis | Skills typically fired |
|---|---|---|---|
| 10s social loop | 2,3,8,9,10 (light) | Design → Model → Rig → 1 shot anim → render | character-design, modeling, lookdev, rigging, animation, render-comp |
| 1–3 min short film | Almost none | Full journey, pre-production is king | orchestrator + nearly all |
| Game cutscene | 8,9,10 (partial) | Reuse game assets, realtime render (EEVEE) | modeling, lookdev, animation, render-comp, production-finishing (realtime) |
| Stylized character turntable | 2,3,8–12 | Design → Model → Lookdev → Rig → turntable anim | character-design, modeling, lookdev, rigging, animation, lighting, render-comp |
| Creature VFX shot | 3,4 (partial) | Creature design → sculpt → rig → creature anim → sim | character-design, sculpting-anatomy, modeling, rigging, animation, simulation, vfx, render-comp |
| Architectural/landscape film | 4–8 (character stages) | Environment → camera → lighting → render | environment, cinematography, lighting, render-comp |
| Abstract/experimental | 2–12 mostly | Geometry nodes → sims → VFX → compositing | environment, simulation, vfx, render-comp |
| Realistic human | — | Anatomy, scan/retopo, skin/eye shaders, facial rig, acting | sculpting-anatomy, modeling, lookdev, rigging, animation |

The orchestrator customizes the 34-stage journey using this table **before** firing skills.
