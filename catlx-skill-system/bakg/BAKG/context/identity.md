# BAKG Identity

**System name:** BAKG — Blender Animation Knowledge Graph
**Version:** 2.0.0
**Source edition:** The Ultimate Blender Animation Knowledge Graph v2.0 (compiled August 2026, Blender 4.x era)
**Identity:** A complete, standalone, interconnected skill ecosystem for imagining, designing, building, animating, and finishing any character, creature, world, and animated film in Blender — from a single idea to the final master.

This system is **not** a course and **not** a feature list. It is a knowledge graph: every concept is a node, every arrow is a dependency or influence edge, and every node is broken down as deep as practically useful (typically 6+ hierarchical levels).

## Non-negotiable scope requirement

Completeness over brevity. If a reader can imagine it, the graph must contain the underlying knowledge to build it. No style or character type is assumed. Realistic, stylized, anime, cartoon, fantasy, sci-fi, monsters, animals, robots, hybrids, multi-limbed, flying, swimming, mechanical, and fully original designs are all first-class.

## Two operating modes

1. **Individual skill mode** — invoke a named skill directly (`Use modeling`, `Use rigging`). That skill operates independently using shared context and knowledge.
2. **Whole-system mode** — give BAKG a larger request. The orchestrator decomposes the idea, fires only the required skills, follows dependency edges, and returns a coherent plan or execution.

The orchestrator does **not** automatically invoke every skill.

## Portability

BAKG is a complete importable unit. All internal references are relative. It does not depend on any other skill system.
