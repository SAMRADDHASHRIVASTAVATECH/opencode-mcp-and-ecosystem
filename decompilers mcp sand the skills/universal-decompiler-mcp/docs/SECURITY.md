# Security and authorization
Use only for owned/authorized software, interoperability, CTFs and isolated research. The MCP never launches targets, debugs live processes, bypasses DRM/licensing/authentication, patches binaries or unpacks by execution. Container inspection lists entries without extraction to avoid traversal/decompression bombs.

Analysis and installs require exact, expiring, single-use approval. Installation downloads and executes third-party package code, so source/version/command must be reviewed. Outputs can contain secrets from the target; protect analysis directories. Static analysis is not a malware sandbox.
