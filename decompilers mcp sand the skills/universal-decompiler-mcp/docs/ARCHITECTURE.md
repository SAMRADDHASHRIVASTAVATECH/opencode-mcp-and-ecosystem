# Architecture
MCP → path/security boundary → multi-signal identifier → capability router → persistent dynamic registry → curated installation planner → adapters → static analysis pipeline → artifact manifest/report.

Adapters invoke argv arrays with `shell=False`, bounded timeout/output and no target execution. New tools are data-first catalog entries plus an invocation/parser adapter. Registry scanning is live and persistent. Pipelines create identification, metadata, strings, imports, exports, symbols, disassembly, decompilation, reconstruction, verification and reports directories without modifying the target.
