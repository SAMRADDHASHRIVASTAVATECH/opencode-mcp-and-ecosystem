# Technology research record (10 September 2026)
Primary references: Microsoft Windows.Graphics.Capture and interop documentation; Microsoft keyboard input/SendInput documentation; Microsoft UI Automation documentation; DXcam PyPI/GitHub; pywinauto documentation; Tesseract documentation; Model Context Protocol Python SDK/FastMCP documentation. DXcam 0.3.0 was published in March 2026 with Windows wheels and MIT licensing. FastMCP is used with a compatibility import because its standalone and official-SDK APIs have changed across major versions. See the preserved feasibility PDF one directory above for the source architecture and game-specific research.

Key correctness findings: GraphicsCaptureItem can target HWND/HMONITOR but requires D3D/WinRT interop; Desktop Duplication is practical for high-rate Python monitor capture. SendInput is blocked across higher integrity levels and cannot verify application acceptance. UIA is preferred for accessible controls but not all apps expose it. Tesseract is local/offline but game/scene text needs tuning. Language models must remain outside frame-rate loops.
