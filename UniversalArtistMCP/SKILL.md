# Universal Artist Skill

## Operating contract
Maintain one `ArtworkState` per project. Convert requests into object/layer/constraint edits, not a fresh picture. Ask only for consequential ambiguities. Analyze brief, audience, medium, dimensions, references and deliverables; produce concepts; select with rationale; construct from large forms to detail; critique against brief; correct; preflight; save editable master plus exports.

Use the Artist MCP for state, plan, app discovery, trajectories, critique and action envelopes. Use the Visual MCP for deterministic computation, artifacts and DAGs. Use Windows Live Control only for approved live observation/action.

## Reliability order
Native document/API → supported plugin → script → CLI → accessibility/UIA → visual grounding → user-mode raw input. Verify after every meaningful operation; retry at most twice with a changed method, then stop and explain.

## Unknown application
Discover executable/version, inspect accessibility and documented interfaces, identify canvas/window transforms, run a non-destructive probe, record capability profile, request approval, execute, observe, correct. Never infer coordinates from stale screenshots.

## Drawing
Fit paths in canvas coordinates. Clip to canvas and safe window region. Create trajectories with temporal easing, spacing and pressure. Before dispatch require foreground identity, DPI/zoom/scroll calibration, unobscured canvas, bounded path and approval. The Live Agent must release input on abort. A genuine Paint test uses dispatched pointer strokes and post-action observation; importing a bitmap is not drawing.

## Critique rubric
Brief fit; focal hierarchy; silhouette; composition/balance; proportion/perspective; values; palette/color harmony; edge control; typography/grid; artifacts; accessibility; output constraints; editability. Label heuristics as heuristics.

## Generation
Generation is optional ideation/reference/inpainting, never the whole architecture. Preserve prompts/seeds/model metadata and rebuild selected results into editable structure when required.

## Domain authority
Use `research/UNIVERSAL_VISUAL_DISCIPLINES.md` as the discipline/workflow ontology. Classify each request into one or more disciplines, instantiate their specialist workflow profiles, preserve cross-disciplinary constraints, and require qualified review for regulated or safety-critical claims.
