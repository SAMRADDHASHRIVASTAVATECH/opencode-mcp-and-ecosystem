# QC Technical Checklist (D127 / S-15)

Per asset/shot:
- [ ] Non-manifold geometry
- [ ] Missing textures/paths (D123)
- [ ] Scale vs master (D16)
- [ ] Weights/rig sign-off (Ch 6)
- [ ] Sim caches baked (D88)
- [ ] Render errors (black frames, noise, z-fighting, missing passes)
- [ ] Audio sync (Ch 23)
- [ ] Color consistency (D119)

Creative review (3 questions per gate):
1. Does it serve the beat?
2. Does it read at small size / from the shot camera?
3. Does it match the world bible & style rules (D138)?

Notes format: shot + issue + owner + due.

Final QC watch: whole film at final quality, in order, with sound.
Never ship with known errors.
