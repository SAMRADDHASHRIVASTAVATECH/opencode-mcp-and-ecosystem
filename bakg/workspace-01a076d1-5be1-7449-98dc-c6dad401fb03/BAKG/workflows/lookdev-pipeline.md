# Workflow: Lookdev Pipeline

```
UV plan (D25) → texel density lock
→ maps (albedo, roughness, normal, masks) via paint/photo/proc/bake (D26–D29)
→ Principled materials (D30) / NPR system if stylized (Ch 18)
→ organic: skin (D32), eyes (D33), teeth (D34), tongue (D35), nails/claws (D36)
→ hero close-up under FINAL lighting (not HDRI-only)
→ lookdev lock
```

Handoff checklist lives in `knowledge/domains/ch04-lookdev.md` and `checklists/lookdev-handoff.md`.
