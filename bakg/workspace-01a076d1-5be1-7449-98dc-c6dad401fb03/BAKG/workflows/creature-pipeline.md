# Workflow: Creature Pipeline

```
creature spec sheet (D05)
  locomotion class, mass, skeleton logic, surface, senses, extras
→ design (D04 shape language still applies)
→ anatomy library pick (Ch 16: quadruped/avian/insect/aquatic/limbless/invented)
→ sculpt-first (D22) → retopo (D23) with joint-by-joint atlas (Ch 31)
→ surface: skin/scales/chitin/fur/feathers (lookdev + costume-groom)
→ rig type from decision 5.4 (quad, multi-leg, wing, tail, tentacle)
→ movement from D69–D73 (invented-but-believable)
→ secondary (jiggle, membrane, cloth, hair)
```

Believability checks (must all pass):
1. Could it stand?
2. Could it breathe/eat?
3. Does every decoration have a function or a story?
4. Would its gait match its mass?

If "no," fix the design, not the animation.
