# Example C — Completely original creature (the graph's real test)

Full traversal: `knowledge/system/04-ultimate-test.md` §4.3.

When the creature has NO precedent, the graph does not invent a species name. It asks:

1. Locomotion class (D05)
2. Mass & center of mass
3. Skeleton logic (joint count the animation can support)
4. Surface plan (maps to D32/D44/D45/Ch 17)
5. Sensory plan (drives head + facial rig)
6. Extras: functional vs decorative
7. Believability checks
8. Invented creature toolkit (Ch 16.12)

Then it attaches existing systems (multi-leg gait, tentacle rig, chitin shader, etc.) to the spec.

**The proof:** originality lives in the *combination*, not in missing nodes.
