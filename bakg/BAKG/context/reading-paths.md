# Reading Paths (User Intent → Skills)

From Part 0. Choose the path that matches the user.

| User | Start here | Then |
|---|---|---|
| Complete beginner, want a film | `bakg-orchestrator` + Part 1 journey | foundations → modeling → lookdev → rigging → animation → cinematography → lighting → render-comp |
| Character animator | `rigging` then `animation` | cinematography |
| Creature designer | `character-design` | sculpting-anatomy → modeling → costume-groom → animation (creature locomotion) |
| Environment artist | `environment` | lighting → cinematography |
| VFX / simulation TD | `simulation` + `vfx` | render-comp |
| Solo filmmaker | `bakg-orchestrator` whole-system mode | full 34-stage journey, skip [SIT] that the project type does not need |
| "I have an idea, tell me what to do" | `bakg-orchestrator` Ultimate Test | fire only implied domains; resolve choices with `decision-engine` |

Skip simulation-heavy domains initially for beginners.
